Installation & Scope
Requirements
  • Designed for Odoo 19.0; requires Sales, Accounting, Inventory, and the separately available shati_shopify_register_payment module.
  • The Shopify connector is a required installation dependency even if Shopify workflows are not used.
  • For automatic warehouse selection, link a warehouse to the corresponding branch before processing orders.
Quick setup
  1. Make the dependencies available, then install iWesabe Branch Management from Apps.
  2. Create branches, assign each to a company, and optionally link warehouses.
  3. Assign users a main branch, allowed branches, and the appropriate Branch User or Branch Manager role.
Access-control scope: Branch roles control access to branch records. Branch groups organize branches and do not grant or restrict permissions. This module does not, by itself, add branch-based record rules to every Sales or Accounting document; review your deployment's document access requirements separately.
Module Summary
  • Manages branch information and branch configuration.
  • Supports assigning branches and a main branch to users.
  • Provides branch grouping information.
  • Stores Shopify branch, order and store references on sales orders.
  • Synchronizes Shopify branch information with a related warehouse when available.
  • Stores Shopify branch/reference information on invoices and supports tracing to the related sale order.
