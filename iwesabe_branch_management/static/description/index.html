GETTING STARTED

A simple setup path

Configure your branches first, then connect users, warehouses and transactions.

01 / SET UP

Create your branches

Settings → Users & Companies → Branches

Create a record for each branch. Add its name, company and branch code, then complete any contact, address, state, tax or document-term information you use.

Tip: Use a consistent branch code so teams can identify branches quickly.
02 / ASSIGN

Configure user access

Settings → Users & Companies → Users

Open a user and set their allowed branches and main branch. Assign the appropriate Branch access role in the user's access rights.

Access roles: Branch User and Branch Manager. Review branch assignments when responsibilities change.
03 / ORGANIZE

Group branches for reporting

Settings → Users & Companies → Branch Groups

Create a branch group when you want related branches presented together in reporting. Set its name, sequence and any excluded branches.

Branch groups are intended for organizing reporting data; they do not replace user branch assignments.
04 / CONNECT

Link warehouses to branches

Inventory → Configuration → Warehouses

Open a warehouse and select its branch in the Branch field. Configure the warehouse and operation types using your normal Odoo workflow.

For Shopify orders, verify that the branch and warehouse setup matches your connector's order flow.
05 / PROCESS

Review Shopify sales orders

Sales → Orders → Sales Orders

When using the Shopify integration, review the order's Shopify and branch information on the sales order. Confirm that the correct branch and related warehouse are selected for your process.

Shopify fields require the shati_shopify_register_payment module.
06 / TRACE

Follow the branch on invoices

Accounting → Customers → Invoices

Use the Branch field on the invoice and invoice lines to keep accounting records associated with a branch. Shopify invoice references are available through the connector integration.

Check the branch on the resulting invoice as part of your order-to-invoice review.

Requirements

  • Odoo 19.0
  • The module depends on Sales, Accounting and Inventory.
  • The shati_shopify_register_payment module is a required installation dependency. Its Shopify-specific features are needed for Shopify order and invoice workflows.

Before you go live

  • Create branches and set the correct company before assigning users.
  • Give each user only the branch access required for their role.
  • Set the branch on each relevant warehouse.
  • Test a complete sales-to-invoice workflow with your installed connector and configuration.
